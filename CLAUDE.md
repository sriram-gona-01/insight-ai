# Insight AI

Self-hosted question answering over slide decks and PDFs, plus a measured comparison of
text and visual retrieval. `BUILD_SPEC.md` is the source of truth; work milestone by milestone.

## Commands

- `uv sync`: install dependencies
- `make lint`: ruff check and format check
- `make test`: unit tests
- `uv run insight --help`: the CLI

## Pointers

- `docs/decisions.md`: dated decisions and verified facts
- `docs/learning/`: per-milestone notes
